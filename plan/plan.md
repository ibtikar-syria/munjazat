## 1. الملخص التنفيذي

يطرح المقترح الأصلي بناء ذاكرة مؤسسية حول الحضور السوري في تركيا: أفراد، كيانات، ومنجزات. الجداول اليدوية واللجان الورقية لا تكفي لتغطية أنقرة وإسطنبول وغازي عنتاب، ولا تنتج مؤشرات حية وتقارير دورية قابلة للاستخدام الدبلوماسي.

**منجزات** منصة ويب هجينة تحوّل هذا التصور إلى نظام برمجي يحقق:

1. تمكين الجمهور وشبكة الميدان من **تقديم** بيانات الأشخاص والمؤسسات والمنجزات مع الشواهد.
2. تمكين نقاط الاتصال واللجنة الأساسية من **التحقق والتصنيف والاعتماد** عبر مسار حوكمة واضح.
3. تمكين القيادة من **لوحة مؤشرات** (خرائط، قطاعات، أدلة، وتقارير قابلة للتصدير).

## 3. واجهات المنتج


| الواجهة             | الجمهور                      | الغرض                                                                   |
| ------------------- | ---------------------------- | ----------------------------------------------------------------------- |
| البوابة العامة      | الجالية والشركاء             | تعريف المشروع، **تصفّح المنجزات المنشورة**، طريقة التقديم، دليل السجلات |
| معالج التقديم       | أفراد / مؤسسات / متطوعون     | إدخال منظم لشخص أو جهة أو منجز + مرفقات                                 |
| كونسول نقطة الاتصال | أنقرة / إسطنبول / غازي عنتاب | فرز أولي، ملكية جغرافية، إحالة للجنة                                    |
| مساحة عمل اللجنة    | اللجنة الأساسية + الخبراء    | تحقق معمق، تصنيف، وسم شراكات، نشر/رفض                                   |
| إدارة البعثة        | قيادة البعثة                 | المستخدمون، الأدوار، التصنيفات، التدقيق، سياسة النشر                    |
| التحليلات والتقارير | القيادة والمحللون            | مؤشرات، خرائط، مرشحات، تصدير، قصص نجاح                                  |


اللغة الأساسية: **العربية (RTL)** مع تسميات إنجليزية ثانوية عند الحاجة للتواصل المؤسسي الدولي.

### قرارات واجهة المنتج

- **دخول الموظفين** لا يظهر في الشريط العلوي؛ موقعه في **تذييل الموقع** ضمن قسم «الوصول الداخلي» حتى تبقى الواجهة العامة موجّهة للجالية.
- الترويسة العامة تعرض روابط الجمهور: **تصفّح المنجزات**، تقديم توثيق، تتبع الطلب، ولوحة التحكم إن وُجدت جلسة موظّف.
- **الدليل العام** `/browse`: يتيح للزوّار تصفّح المنجزات والكفاءات والجهات ذات الحالة `published` فقط، مع بحث وتصفية بالمدينة، وصفحة تفصيل للمنجز. لا تُعرض بيانات التواصل الخاصة.
- التذييل مؤسسي متعدد الأعمدة: تعريف المنصة، روابط الجمهور (ومنها التصفّح)، نطاق العمل (أنقرة / إسطنبول / غازي عنتاب)، ودخول الموظفين.
- التصميم عربي RTL ومتجاوب للجوال: قائمة طيّ للترويسة على الشاشات الصغيرة، أزرار بعرض كامل حيث يلزم، ولوحة داخلية بأشرطة تنقّل أفقية على الموبايل.
- الهوية البصرية: أخضر غابي + لمسة ذهبية، خط عرض كوفي/عربي، خلفية رملية خفيفة — بدون ثيم بنفسجي افتراضي.

## 4. الأدوار والصلاحيات

مواءمة مع المستويات الثلاثة في المقترح:

- **مدير البعثة**: الحوكمة، المستخدمون، التصنيفات، سياسة النشر النهائية، سجلات التدقيق.
- **رئيس اللجنة**: الإشراف على الطوابير، تعيين المراجعين، اعتماد النشر والتقارير.
- **عضو اللجنة**: مراجعة وتصنيف وفق التخصص (بحث، بيانات، اقتصاد، أكاديميا/ثقافة، مجتمع مدني، شراكات).
- **مسؤول نقطة اتصال**: نطاق جغرافي محدد (أنقرة / إسطنبول / غازي عنتاب)؛ تحقق أولي فقط.
- **خبير / متطوع**: إنشاء محدود وتعليق على سجلات مُسندة؛ بلا صلاحية نشر.
- **مقدّم عام**: تقديم عبر النموذج (تحقق بالبريد)؛ متابعة الحالة برمز تتبع أو رابط آمن.
- **محلل للقراءة فقط**: لوحات وتصدير؛ بلا تعديل.

كل تغيير في الحالة يُسجَّل (من قام به، متى، من→إلى، وملاحظة).

## 5. نموذج البيانات الأساسي

**الكيانات الرئيسية**

- **شخص (كفاءة)**: الاسم، التخصص، المدينة، ملامح تعليمية/مهنية، تواصل (مقيّد)، موافقات النشر.
- **جهة/مؤسسة**: النوع (شركة، منظمة، مجلس، مبادرة، إعلام، أكاديمي، نسائي/شبابي، أخرى)، سنة التأسيس، مدن النشاط، النطاق.
- **منجز**: العنوان، الوصف، الفترة، نطاق الأثر (محلي/وطني/ثنائي)، الشواهد، الربط بأشخاص وجهات.
- **طلب توثيق**: قناة المصدر، بيانات المقدّم، الحمولة، حالة المسار، نقطة الاتصال المسندة.
- **تصنيفات**: القطاع، نوع الجهة، المدينة/المحافظة، نطاق الأثر، حجم/طبيعة المنجز (قابلة للتعديل من الإدارة).
- **شاهد/دليل**: ملفات أو روابط (شهادات، صحافة، وثائق تسجيل) مع قواعد احتفاظ.
- **لقطة تقرير**: استعلام مجمّد + كتل سردية للتقارير الدورية/السنوية.
- **قصة نجاح**: سرد قابل للنشر مرتبط بسجلات موثّقة.

**أبعاد التصنيف** (من المقترح): القطاع، المدينة، نوع الجهة، مجال النشاط، فترة التأسيس، نطاق الأثر، طبيعة/حجم المنجز.

**الملكية الجغرافية**: كل مدينة تُربط بنقطة اتصال واحدة؛ تُوجَّه الطلبات تلقائياً حسب المدينة.

## 6. مسار التحقق والنشر

```
مسودة → مُقدَّم → مراجعة نقطة الاتصال → مراجعة اللجنة → موثَّق → منشور
                              ↘ يحتاج استكمال ↗
                              ↘ مرفوض
المنشور → مؤرشف (عند إلغاء النشر)
```

**قواعد**

- الدليل العام وواجهات البرمجة العامة تعرض **المنشور** فقط.
- اللوحات الداخلية ترى كل الحالات بحسب الدور.
- كشف التكرار (الاسم + المدينة + النوع / تطابق تقريبي) قبل الدمج في اللجنة.
- تقليل البيانات الشخصية قبل النشر (إخفاء الهاتف/البريد؛ نشر ملخص الملف فقط).

## 7. وحدات لوحة التحكم

1. **لوحة العمليات**: طوابير حسب الحالة، عمر الطلب، حمل نقاط الاتصال، المُسند إليه.
2. **خريطة التغطية**: السجلات حسب المدينة/المحافظة؛ تصفية بالقطاع ونوع الجهة.
3. **ذكاء قطاعي**: أعداد واتجاهات (اقتصاد، أكاديميا، مجتمع مدني، إعلام، نساء/شباب…).
4. **عرض الشبكة**: أشخاص ↔ جهات ↔ منجزات.
5. **عدسة الشراكات**: وسوم تعاون سوري–تركي–دولي.
6. **استوديو التقارير**: حفظ المرشحات كلقطة؛ تصدير Excel؛ ملخص PDF عربي للبعثة.
7. **الحوكمة**: مستخدمون، دعوات، محرر تصنيفات، سجل تدقيق، قائمة موافقة/نشر.

الجانب العام: صفحة هبوط، **دليل تصفّح منشور** (`/browse` + تفصيل المنجز)، معالج تقديم، صفحة تتبع.

## 8 الأمن والخصوصية والحوكمة الدبلوماسية

- حسابات الموظفين بدعوة فقط؛ يُفضَّل التحقق الثنائي (TOTP).
- حذف منطقي + سجل تدقيق؛ لا إجراءات إدارية مجهولة.
- إخفاء حقول التواصل داخلياً ما لم يوافق صاحب البيانات على المشاركة مع البعثة.
- موافقة عند التقديم (الغرض، الاحتفاظ، حق طلب التصحيح).
- استعلامات مقيّدة بالدور (نقطة الاتصال لا تعدّل خارج مدنها).
- نسخ احتياطي دوري

## 10. خارج نطاق النسخة الأولى

- تطبيقات جوال أصلية (الويب المتجاوب كافٍ).
- تصنيف آلي بالذكاء الاصطناعي كسلطة وحيدة (مساعدة اختيارية لاحقاً بعد استقرار المسار البشري).
- منصة متعددة الدول كخدمة جاهزة (يُترك المجال لإضافة `mission_id` لاحقاً؛ الإطلاق لتركيا فقط).
- شبكة تواصل اجتماعي أو مراسلة بين أبناء الجالية.

## 11. معايير النجاح

- وجود مسار إدخال منظم واحد على الأقل يستخدمه الجمهور ونقاط الاتصال.
- كل سجل منشور له تاريخ تحقق ووسوم تصنيف.
- قدرة القيادة على الإجابة: «كم جهة موثّقة لكل مدينة/قطاع؟» دون جداول يدوية.
- أول تقرير جاهز للبعثة قابل للتصدير من النظام خلال الشهر السادس.
- مسؤولو نقاط الاتصال يرون طابور نطاقهم الجغرافي فقط.

## 12. المخرجات المتوقعة من المنصة

- قاعدة بيانات مؤسسية للكفاءات والجهات والمنجزات.
- فهرس قابل للبحث والتصفية.
- خريطة قطاعية وجغرافية لرأس المال البشري والمؤسسي.
- تقارير دورية/سنوية ومؤشرات لدعم الشراكات واتخاذ القرار.
- قصص ونماذج نجاح موثّقة.
- نموذج تقني قابل للتطوير لبعثات أخرى مستقبلاً.
