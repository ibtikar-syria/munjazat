# Munjazat Frontend

Vite + React Arabic RTL portal and staff dashboard.

## Local setup

```bash
npm install
npm run dev
```

Proxies `/api` to `http://127.0.0.1:8787` (run the backend first).

## Pages

- `/` public landing
- `/submit` public submission form
- `/track` tracking by code
- `/login` staff login
- `/dashboard/*` internal console
